## Implemented with synthetic regression coverage

- Rust daemon serving authenticated local Unix-socket IPC, external Dart engine adapter, encrypted SQLite storage/keychain integration, idempotent message ingestion and persistence before inbound fanout.
- TUI conversation list, local stored transcript, sender grouping, text composition/sending, existing/new-chat correlation, event-driven delivery labels, uncertain-outcome warnings and explicit failed-draft recovery.
- Recipient-owned durable drafts (debounced to the daemon's encrypted store over IPC v7, bounded retention, exact-owner restore, delete on send or explicit cancel) and modal suspension, literal bracketed paste, grapheme editing/wrapping, exact multiline whitespace, responsive resize, and session-only composer undo/redo that clears when the draft changes owner.
- On-demand older-page loading from local storage: reaching the oldest loaded row fetches the previous keyset page, keeps it across reconciliation for chats you paged back, and bounds retained paged history. Chats you never paged still replace wholesale, and no remote history is fetched.
- Message-owned reading anchors across arrivals/reconciliation/edits/reflow and canonical identities; measured mouse/End Latest action and painted-overlay wheel ownership.
- Local unread badges and `/unread` or Ctrl+B then `u` navigation over loaded incoming messages. Markers advance only after a successfully displayed latest transcript, migrate across aliases, and persist in private but unencrypted TUI preferences. No marker or loaded history means unknown unread state, not zero. These are not remote read receipts.
- Below 70 columns, full-width conversations with a searchable Chats navigator. Query/candidate stay separate from actual recipient and parked composition until explicit open.
- Known-participant contacts/search/local nicknames, local titles/hiding, conversation filtering, settings/theme/command pickers, keyboard/mouse paths, light/dark/automatic themes and monochrome cues.
- Metadata `/sync` with explicit in-flight lifetime and post-refresh local reread. Inbound message/update/delivery/list events infer activity until two quiet seconds. Failed/blocked/disconnected session states outrank activity. This is not archive completion.
- Coalesced redraw scheduling, responsive identity/status priority and neutral selection surfaces. A four-entry session-only transcript layout cache and visible-line painting avoid repeated whole-history work during warm switching; cold or changed large histories and IPC refresh remain separate costs.
- Installed `bloom` command with sibling/PATH companions, owned-child cleanup, reused-daemon preservation, bounded drain and terminal restoration. Cargo installs binaries only; the sidecar/Dart/engine/registration remain external runtime prerequisites.
- Generation-scoped engine recovery after a successful start: old generations drain and join before bounded replacement, crash-loop budgets reset only after a 60-second stable window, and uncertain sends are never replayed. A synthetic real-child test proves replacement. One authorized live probe killed the real sidecar child; the old PID was reaped, a different child appeared after 0.42 s, and its session became active. Message transfer, repeated recovery, daemon restart, renewal and ABI remain unverified.
- Inbound built-in reactions map to typed events, update only a stored target's reaction list, fan out through the existing update event, survive fixture history/context/restart, and render as sorted aggregate counts in the real TUI PTY. Outbound reaction capability remains false and no send operation exists.
- Inbound edits and unsends preserve engine part identity in the encrypted store, require target/sender/conversation/part/timestamp evidence, apply in one transaction, and reject ambiguous legacy rows rather than guessing. An edit replaces only its evidenced part group with nonempty text; a whole-body unsend retains content and reactions. Display is truthful and PTY-proven at 100/44/24 columns. Partial multipart unsend and edits after unsend are explicitly unsupported.
- Outbound attachment send over IPC v9: `/attach <absolute path>` validates one local file (absolute, regular, non-symlink, no `.`/`..`, 1 to 25 MiB), uploads it through the sidecar with inferred MIME/UTI, sends one attachment part, records one outbound stored part, and reports a timeout as uncertain without retry. Rust, Dart and real-TUI PTY coverage pass; a live engine upload of a 33-byte file completed, but the engine rejected the only safe self-pair send with `no_valid_targets`; remote delivery, echo/dedupe and limits remain unverified and need a named third-party target.
- Sidebar viewport scrolling: wheel over the chat list scrolls a persistent viewport without changing the selected chat; an overflow scrollbar supports track click/drag; every painted chat row, including the last at the bottom, is clickable; selecting during new-chat composition parks that draft and clears the mode; keyboard selection reveals the selected row. App/render tests and a real 24-chat PTY flow pass; no live access.
