# Third-party notices

Generated by `scripts/generate-third-party-notices`. Do not edit by hand.

- Rust: 485 external packages, 299 unique notice files copied.
- Dart: 52 external packages, 25 unique notice files copied.
- Fallbacks: 48 Rust packages use `fallbacks/` because no
  package-specific license file was present; their list is in
  `fallbacks/README.md`. Dart packages without a license file are marked
  `NO FILE` in their manifest.

The manifests list every package with its version, declared license, repository
and the notice files included here. `licenses/` is deduplicated by content.
`fallbacks/` contains generic MIT, Apache-2.0 and MPL-2.0 texts; a fallback is
not a substitute for a package-specific copyright notice and must be reviewed
before distribution.

The external OpenBubbles engine is not included. Its licensing and ABI range are
separate release blockers. No legal advice is provided by this bundle.
